# 企业微信智能文档导出 Markdown

一个用于 Tampermonkey、Violentmonkey 等用户脚本管理器的油猴脚本，将企业微信智能文档导出为本地 Markdown 文件。

脚本会使用当前浏览器中已登录的企业微信会话读取文档内容，不需要复制粘贴，也不需要额外配置 API 密钥。

## 功能特性

- 在企业微信智能文档页面右下角添加“导出 Markdown”按钮。
- 自动读取当前文档的完整区块内容，支持分页加载。
- 将常见文档结构转换为 Markdown：
  - 普通文本
  - 一级、二级、三级标题
  - 有序列表和无序列表
  - 引用块
  - 分隔线
  - 表格
  - 粗体文本
- 自动处理 Markdown 特殊字符，尽量避免导出内容破坏 Markdown 格式。
- 根据文档标题生成文件名，并自动清理操作系统不允许的文件名字符。
- 导出的文件使用 UTF-8 编码，并保存为 `.md` 文件。
- 不依赖第三方服务，脚本只请求企业微信当前站点的文档接口。

## 使用环境

- 已登录企业微信，并且拥有目标文档的查看权限。
- 支持用户脚本的浏览器，例如：
  - Chrome / Chromium
  - Microsoft Edge
  - Firefox
- 已安装以下任一用户脚本管理器：
  - [Tampermonkey](https://www.tampermonkey.net/)
  - [Violentmonkey](https://violentmonkey.github.io/)

## 安装

### 方法一：从脚本文件安装

1. 安装 Tampermonkey 或 Violentmonkey。
2. 打开脚本文件：[`WeChatDoc2MD.js`](./WeChatDoc2MD.js)。
3. 将文件内容复制到用户脚本管理器中新建的脚本中，保存。
4. 打开或刷新企业微信智能文档页面。

### 方法二：从 GitHub 安装

在油猴的`管理面板`中切换到`实用工具`选择`从 URL 安装`，从以下地址安装：
```text
https://raw.githubusercontent.com/wlianmin/WeChatDoc2MD/main/WeChatDoc2MD.js
```

## 使用方法

1. 在浏览器中登录企业微信。
2. 打开需要导出的企业微信智能文档，并确认自己拥有查看权限。
3. 等待页面加载完成。
4. 点击页面右下角的 **导出 Markdown** 按钮。
5. 等待按钮显示“导出完成”。浏览器会自动下载一个与文档标题同名的 `.md` 文件。

示例：

```text
企业微信智能文档：项目说明
导出文件：项目说明.md
```

## 支持的 Markdown 转换

| 企业微信文档内容 | Markdown 输出 |
| --- | --- |
| 普通段落 | 普通文本 |
| 一级标题 | `# 标题` |
| 二级标题 | `## 标题` |
| 三级标题 | `### 标题` |
| 有序列表 | `1. 项目` |
| 无序列表 | `- 项目` |
| 引用块 | `> 引用内容` |
| 分隔线 | `---` |
| 表格 | 标准 Markdown 表格 |
| 粗体文本 | `**粗体文本**` |

## 注意事项与限制

- 当前脚本只匹配企业微信智能文档地址：

  ```text
  https://page.weixin.qq.com/smartpage/p/*
  ```

- 必须在已登录且有文档查看权限的浏览器页面中使用。
- 脚本读取的是企业微信接口返回的文档区块，不是简单抓取当前页面上已经渲染的文字，因此页面显示不完整时仍可能正常导出；但如果接口权限或接口格式发生变化，导出可能失败。
- 当前版本主要面向文字内容导出，图片、附件、复杂嵌套结构、特殊嵌入组件等内容可能无法转换为 Markdown。
- 表格第一行会作为 Markdown 表头；不规则表格会自动补齐空单元格。
- 导出过程中请勿关闭当前文档页面或退出登录。
- 文档内容可能包含敏感信息，请妥善保管下载的 Markdown 文件。

## 常见问题

### 看不到“导出 Markdown”按钮

请检查：

1. 用户脚本管理器已经安装并启用该脚本。
2. 当前地址是否以 `https://page.weixin.qq.com/smartpage/p/` 开头。
3. 页面是否已经完成加载；可以尝试刷新页面。
4. 浏览器是否阻止了用户脚本运行。

### 点击后提示“未取得文档标识”

通常表示当前浏览器没有有效的企业微信登录态，或者当前账号没有文档查看权限。请重新登录企业微信并确认可以正常打开文档后再试。

### 点击后提示请求失败

可能原因包括：

- 登录态已过期；
- 网络连接异常；
- 企业微信接口临时不可用；
- 企业微信调整了文档接口或返回数据格式。

可以先刷新页面、重新登录后重试。如果问题持续存在，请在浏览器开发者工具中查看控制台错误信息，并提交 Issue，同时隐藏文档内容、Cookie 和其他敏感信息。

### 下载的文件名不符合预期

脚本会使用文档标题作为文件名，并将 `\\ / : * ? " < > |` 等系统不允许的字符替换为下划线。标题为空时，默认文件名为 `企业微信文档.md`。

## 隐私与安全

- 脚本不会将文档内容上传到第三方服务器。
- 脚本使用当前页面的企业微信登录态访问同源文档接口。
- 脚本会在浏览器本地生成 Markdown 文件并触发下载。
- 请仅在自己信任的用户脚本管理器中安装脚本，并在发布前审查脚本代码。

## 开发与调试

脚本为单文件 JavaScript，不需要构建步骤。修改 [`WeChatDoc2MD.js`](./WeChatDoc2MD.js) 后，在用户脚本管理器中保存并刷新企业微信文档页面即可验证。

调试时可以打开浏览器开发者工具的 Console 面板。脚本发生异常时会输出带有 `[Markdown Export]` 前缀的错误信息。
